`bin/archive-logs.sh` and `README.md` changed. Rewrote the script to accept multiple service names, added `--keep-days N` pruning (per-service, applied after new archives land), and a one-line summary. Along the way fixed the pre-existing bugs that a multi-service loop would have made worse: unquoted variables, a predictable `/tmp` path (now `mktemp -d` with a trap), and no validation — added a service-name allowlist regex to block path traversal (`../etc` and similar are now rejected) and a check that each service's log directory exists before anything is archived. Verified syntax, a two-service run, `--keep-days` actually pruning old-dated archives while leaving current ones, and the three error paths (bad service name, missing log dir, non-numeric `--keep-days`).
